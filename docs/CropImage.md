# 图像精确裁剪 (CropImage)

## 1. 功能概述
从源图像中裁剪出感兴趣的局部区域（ROI）。支持矩形模式与中心模式，内置边界安全钳制保护。

## 2. 核心特性
- **双模式支持**：
  - `Rect` 模式：指定起点 `(x, y)` 与宽高 `(w, h)`。
  - `Center` 模式：以指定点为中心向四周扩展 `(w, h)` 进行对称裁剪。
- **自动越界钳制**：遇到边缘溢出自动限制在画布边界内，杜绝内存越界崩溃。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 输入图像（路径或变量） |
| `rect` | `MixedType` | `"0, 0, 200, 200"` | 裁剪区域坐标或尺寸（`x, y, w, h` 或 `w, h`） |
| `crop_mode` | `MixedType` | `"Rect"` | 裁剪模式：`Rect`（自由坐标）或 `Center`（中心锚点） |
| `output_path` | `MixedType` | `""` | 可选保存路径，留空返回图像对象 |

## 4. 输出
- 返回裁剪后的图像对象 `Image`。
