# 智能图像二值化 (ImageThreshold)

## 1. 功能概述
工业级图像二值化算子。合并并统一了传统固定阈值、自动 Otsu（大津法全局最优类间方差）以及 Adaptive（局部积分自适应阈值）三种模式。

## 2. 核心特性
- **三合一统一封装**：无需在多个割裂的二值化插件之间跳转，通过一个 `method` 属性随心切换。
- **自动抗光照不均**：在阴阳脸、光照渐变、纸质泛黄场景下，`Adaptive` 模式基于局部积分均值计算动态阈值，文字笔画完整不粘连。
- **反相自适应**：支持 `invert` 翻转黑白极性（白底黑字 vs 黑底白字）。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 待二值化图像 |
| `method` | `MixedType` | `"Otsu"` | 二值化方法：`Otsu`（自动最佳）、`Fixed`（固定阈值）、`Adaptive`（局部自适应） |
| `thresh` | `MixedType` | `128` | 固定阈值大小（0 ~ 255，在 `Fixed` 模式下生效） |
| `block_radius` | `MixedType` | `5` | 局部块半径（在 `Adaptive` 模式下生效，默认 5） |
| `invert` | `MixedType` | `0` | 是否反相（`1` 是，`0` 否） |
| `output_path` | `MixedType` | `""` | 可选保存路径 |

## 4. 输出
- 返回二值化后的黑白图像对象 `Image`。
- 上下文变量 `computed_threshold`：在 `Otsu` 模式下返回自动计算出的最佳阈值。
