# 颜色区间掩码提取 (ImageInRange)

## 1. 功能概述
在 HSV 或 RGB 空间根据指定的色彩上下界范围（Lower Bound ~ Upper Bound），提取目标颜色区间的二值掩码（Mask）。

## 2. 核心特性
- **公章与红头文件提取**：将彩色文档转入 HSV 空间，指定红色范围（例如 `0, 100, 100` 至 `10, 255, 255`），完美剥离出纯净公章掩码，过滤黑色印刷文字。
- **背景杂色剔除**：在视频监控与工业打标中迅速剥离特定色调的物体。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 源图像（路径或变量） |
| `lower_bound` | `MixedType` | `"0, 100, 100"` | 色彩下界（`'h, s, v'` 或 `'r, g, b'`） |
| `upper_bound` | `MixedType` | `"10, 255, 255"` | 色彩上界（`'h, s, v'` 或 `'r, g, b'`） |
| `color_space` | `MixedType` | `"HSV"` | 色彩空间：`HSV` 或 `RGB` |
| `output_path` | `MixedType` | `""` | 可选保存路径，留空返回图像对象 |

## 4. 输出
- 返回黑白掩码图像对象 `Image`（符合区间的像素为白色 255，其余为黑色 0）。
- 上下文变量 `mask_foreground_ratio`：符合区间的前景像素占全图的比例（0.0 ~ 1.0）。
