# 图像比对与变动分析 (ImageComparison)

## 1. 功能概述
合并原 `ImageSimilarity` 与 `ImageDifference`，提供一站式视觉相似度量化评分与画面差异像素变动检测。

## 2. 核心特性
- **归一化相似度度量**：基于绝对像素平均差（$1.0 - \text{MAD} / 255$），输出 0.0 ~ 1.0 的平滑连续相似度分值，用于 UI 自动化渲染完成断言。
- **差异像素占比统计**：统计产生明显颜色偏离的像素占全图比例。
- **视觉红框差分图输出**：可选生成以半透明红色高亮标出画面变动区域的差分掩码图，并写入磁盘供人机协同审查。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image_a` | `MixedType` | - | 基准基准图 A（路径或变量） |
| `image_b` | `MixedType` | - | 待比对图 B（路径或变量） |
| `diff_threshold` | `MixedType` | `15` | 单像素颜色差异判定容差（0 ~ 255） |
| `diff_output_path` | `MixedType` | `""` | 可选红色高亮差异对比图保存路径 |

## 4. 输出
- 返回视觉相似度评分（Real，范围 0.0 ~ 1.0，1.0 表示完全相同）。
- 上下文变量：
  - `diff_pixel_ratio`：差异像素占整图总像素的比例（0.0 ~ 1.0）。
  - `diff_pixel_count`：产生差异的像素总数。
