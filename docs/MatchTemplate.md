# 模板匹配定位 (MatchTemplate)

## 1. 功能概述
`MatchTemplate` 算子是 RPA 界面自动化中核心的视觉定位工具。基于 NCC（归一化互相关，Normalized Cross-Correlation）算法，在目标大图（屏幕截图或控件图像）中快速检索子模板图像。

## 2. 核心特性与工业痛点解决
- **多尺度 DPI 自适应**：内置金字塔多尺度缩放搜索，完美解决不同屏幕高分屏缩放（100%、125%、150%、200%）导致模板尺寸微变失配的行业顽疾。
- **免胶水点位直出**：直接返回目标中心点 `Point(x, y)`，无需用户手动叠加宽高偏移行程，可直接管道传递至鼠标点击动作。
- **搜索区域限制 (ROI)**：支持局部区域搜索，成倍提升检索帧率与降低误检率。
- **可视化调试图**：支持保存带绿色命中框与红色十字准星的标记图，排查现场误匹配立竿见影。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `source` | `MixedType` | - | 源大图（支持内存 `Image` 对象引用、本地文件路径或 Base64） |
| `target` | `MixedType` | - | 待匹配的模板小图（`Image` 对象或文件路径） |
| `precision` | `MixedType` | `0.8` | 置信度阈值（0.0 ~ 1.0），高于此值视为命中 |
| `search_region` | `MixedType` | `""` | 搜索 ROI 区域，格式 `'x, y, w, h'` 或 `Rect` 对象，留空全图搜索 |
| `multi_scale` | `MixedType` | `0` | 是否启用多尺度 DPI 金字塔搜索（`1` 开启，`0` 关闭） |
| `debug_save_path` | `MixedType` | `""` | 可选调试图保存路径，非空时自动保存带标注的结果图 |

## 4. 输出变量
- **返回值**：命中的模板中心坐标 `Point` 实体对象（包含 `.x` 与 `.y` 属性）。
- **上下文变量**：
  - `matched_confidence`：最佳匹配置信度数值（0.0 ~ 1.0）。
  - `matched_rect`：命中目标的绝对外接矩形 `Rect(x, y, w, h)`。
