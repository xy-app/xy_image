# 形态学操作 (ImageMorphology)

## 1. 功能概述
执行经典的二值数学形态学操作：膨胀（Dilate）、腐蚀（Erode）、开运算（Open）与闭运算（Close）。

## 2. 核心特性
- **开运算（先腐蚀后膨胀）**：平滑物体轮廓，消除孤立毛刺微小噪点，断开狭窄细小颈部。
- **闭运算（先膨胀后腐蚀）**：桥接细小缝隙，填平物体边缘凹坑，闭合断开的字符笔画。
- **结构元范数控制**：支持切比雪夫矩形范数（`LInf`）与曼哈顿十字菱形范数（`L1`）。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 二值灰度图像源 |
| `operation` | `MixedType` | `"Open"` | 形态学操作：`Open`（去噪）、`Close`（填孔）、`Dilate`（加粗）、`Erode`（细化） |
| `radius` | `MixedType` | `1` | 结构元核半径（1, 2, 3...） |
| `norm` | `MixedType` | `"LInf"` | 结构元形状：`LInf`（矩形框）、`L1`（菱形十字） |
| `output_path` | `MixedType` | `""` | 可选保存路径 |

## 4. 输出
- 返回形态学处理后的二值图像对象 `Image`。
