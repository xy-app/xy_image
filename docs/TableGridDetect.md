# 表格网格检测与单元格提取 (TableGridDetect)

## 1. 功能概述
利用纯视觉形态学游程滤波算法，自动提取表格图像中的横向水平线与纵向垂直线，并计算网格交点拓扑切割出单元格矩阵。

## 2. 核心特性
- **免 OCR 快速结构化**：在无需高功耗大模型或 OCR 介入的情况下，直接还原物理表格行数、列数以及每一个单元格的像素 `Rect`。
- **结合 OCR 定向识别**：配合后续 OCR 循环裁剪单元格单独识别，彻底解决 OCR 乱串行、跨列混淆的致命痛点。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 表格图像源 |

## 4. 输出
- 返回外接轮廓数量（Number）。
- 上下文变量：
  - `table_cells`：单元格矩形列表（`Vec<Rect>`）。
  - `table_row_count`：检测到的表格行数。
  - `table_col_count`：检测到的表格列数。
