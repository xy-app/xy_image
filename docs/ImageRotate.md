# 图像旋转与翻转 (ImageRotate)

## 1. 功能概述
对图像进行 90°/180°/270° 正交顺时针旋转，以及水平/垂直镜像翻转。

## 2. 核心特性
- **无损正交**：正交旋转仅进行像素下标重映射，无任何模糊损失与多余插值伪影。
- **扫描件方向纠偏**：可快速校正发票、证件、合同扫描件的朝向。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 源图像 |
| `angle` | `MixedType` | `90` | 顺时针旋转角度（0, 90, 180, 270） |
| `flip` | `MixedType` | `"none"` | 镜像翻转：`none`（不翻转）、`horizontal`（水平）、`vertical`（垂直） |
| `output_path` | `MixedType` | `""` | 可选保存路径 |

## 4. 输出
- 返回旋转翻转后的图像对象 `Image`。
