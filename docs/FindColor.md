# 区域找色与色块定位 (FindColor)

## 1. 功能概述
在源图像或指定矩形区域内搜索匹配指定颜色的像素或色块。常用于无图场景下的按钮状态检索、高亮焦点定位及指示灯变色捕获。

## 2. 核心特性
- **偏色容差控制**：支持 RGB 三通道最大距离容差（0 ~ 255），适应轻微抗锯齿或渐变色差。
- **定位模式自选**：
  - `first`：极速扫描模式，命中第一个符合像素即刻返回。
  - `centroid`：形态学连通色块质心模式，计算所有命中像素几何质心中心，确保点击正中。
- **直接坐标输出**：输出 `Point(x, y)`，无缝衔接鼠标操作。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 源图像 |
| `color` | `MixedType` | `"#FF0000"` | 目标颜色，支持 HEX（`#RRGGBB`）或 `r, g, b` |
| `tolerance` | `MixedType` | `10` | 偏色容差（0 ~ 255） |
| `search_region` | `MixedType` | `""` | 搜索 ROI 区域，留空全图检索（`x, y, w, h`） |
| `find_mode` | `MixedType` | `"Centroid"` | 定位模式：`Centroid`（色块质心）或 `First`（首个像素） |
| `debug_save_path` | `MixedType` | `""` | 可选调试标记截图保存路径 |

## 4. 输出
- 返回目标中心坐标 `Point`。
- 上下文变量 `matched_pixel_count`：命中的符合颜色像素总数。
