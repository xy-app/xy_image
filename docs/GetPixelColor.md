# 像素拾色与状态判定 (GetPixelColor)

## 1. 功能概述
获取指定 `(x, y)` 坐标位置的像素颜色十六进制值，并可选择与期望颜色快速比对，微秒级判定状态。

## 2. 核心特性
- **微秒级性能**：避免整图遍历，单点读取延迟在纳秒~微秒级。
- **指示灯与按钮状态断言**：在自动化运维、工业 SCADA 界面监控中，一键判断运行灯（绿/红）、报警灯是否闪烁亮起。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `image` | `MixedType` | - | 源图像 |
| `coord` | `MixedType` | `"100, 100"` | 待测坐标，支持 `'x, y'` 或 `Point` 对象 |
| `expected_color` | `MixedType` | `""` | 可选的期望颜色 HEX（例如 `'#00FF00'`） |
| `tolerance` | `MixedType` | `10` | 判定容差（0 ~ 255） |

## 4. 输出
- 返回实际像素颜色 HEX 字符串（例如 `"#00FF00"`）。
- 上下文变量 `is_color_match`：当设置期望颜色时，输出 `1`（匹配）或 `0`（不匹配）。
